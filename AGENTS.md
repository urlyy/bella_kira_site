# AGENTS.md

## Project

This project is a fan/support website for Bella Kira, a member of A-SOUL.

The site should promote Bella, help new visitors understand her appeal quickly, and give existing fans a beautiful, playful place to revisit music, stages, birthday events, fan culture, and interactive surprises.

Do not start coding the website until the user explicitly asks to begin implementation.

Keep this file focused on confirmed, durable product and implementation decisions rather than temporary research notes or source dumps.
